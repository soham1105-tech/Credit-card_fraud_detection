# Credit Card Fraud Detection

A Machine Learning project built using Python and Scikit-learn to detect fraudulent credit card transactions using Logistic Regression. This project demonstrates the complete ML workflow, including preprocessing, model training, prediction, and evaluation.

## Overview

The objective of this project is to classify credit card transactions as fraudulent or legitimate using supervised machine learning techniques.

## Technologies Used

* Python
* Google Colab
* NumPy
* Pandas
* Scikit-learn

## Features

* Data preprocessing
* Train-test splitting
* Logistic Regression model
* Fraud prediction system
* Accuracy evaluation

## Model Performance

* Training Accuracy: ~96%
* Testing Accuracy: ~91%

The model shows strong generalization with minimal overfitting.
